# Notices and attribution

## pytest-html-reporter

This plugin is a companion to [pytest-html-reporter](https://github.com/prashanth-sams/pytest-html-reporter),
Copyright (c) 2020 Prashanth Sams, released under the MIT License.

The plugin does **not** bundle pytest-html-reporter. It runs the copy installed in the user's Python environment and
displays the reports that copy generates. `core/ReportPaths.kt` re-implements pytest-html-reporter's rules for where a
report is written (checked against the package by `scripts/upstream_paths.py`), and
`python/pytest_html_reporter_probe.py` asks the installed package for its version, options and configured report
path. The plugin artwork (four descending bars) is derived from the pytest-html-reporter logo by the same author.

The plugin JAR carries this file and [LICENSE](LICENSE) in `META-INF/`.

## Test fixtures (source repository only)

(`scripts/generate-fixtures.sh`). These files are used by the tests only and are **not** included in the plugin
distribution. A generated report embeds the following assets from pytest-html-reporter's `html_page/` folder:
